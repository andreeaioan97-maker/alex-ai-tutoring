Bilingual (EN/RO) static site: home, services and a booking-request calendar.
- Copy for both languages lives in `src/content.mjs`; run `node src/build.mjs` to regenerate the pages (`*.html` and `ro/*.html`).
- Booking settings (Alex's email, optional Calendly link, closed days) are in `assets/config.js`.
- Push to `main`; GitHub Pages redeploys automatically.
